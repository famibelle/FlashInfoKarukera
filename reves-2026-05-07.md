## 🌙 Cycle 1 : Architecture du Player (00:00-00:05)

### Structure Mentale
```
RadioOrchestrator
├── seq[]         (playlist)
├── pos           (position courante)
├── yt            (YouTube Player)
├── ytReady       (flag)
├── trAudio       (HTML5 Audio)
└── _audioCtx     (WebAudio pour EQ)
```

**Insight** : Le player gère 2 sources distinctes (YouTube pour la musique, HTML5 Audio pour liners/capsules).
**Problème latent** : `_playAt()` fusionne chargement + lecture → impossible de séparer les deux.

## 🌙 Cycle 2 : Démarrage Sans Auto-Play (01:00-01:05)

### Flux Idéal
```
start()
  ├─ load()              [async, background]
  ├─ _show()            [UI: cache start-screen]
  ├─ _loadAt(0)         [charge 1er item SANS play]
  │   ├─ type=music  → _showYT() + loadVideoById()
  │   └─ type=liner  → _showTransition() + src=url
  └─ await YT API      [si music, attends onReady]
```

**Risque iOS** : Sans geste utilisateur, `loadVideoById()` peut bloquer.
**Solution onirique** : `_loadAt()` doit être SYNCHRONE. Le `await` YT arrive APRES.

## 🌙 Cycle 4 : Contexte iOS (03:00-03:05)

### Problème
Safari iOS bloque `play()` et `AudioContext` sans geste utilisateur.

### Solution Rêvée
```javascript
// Dans btnPlay click handler (NOUVEL EMPLACEMENT)
const unlock = () => {
  const AC = window.AudioContext || window.webkitAudioContext;
  if (AC) { try { (new AC()).resume(); } catch(_) {} }
  radio.trAudio.volume = 0;
  radio.trAudio.src = 'data:audio/wav;base64,...';
  radio.trAudio.play().catch(() => {});
};
```
**Pourquoi ça marche** : Le clic utilisateur débloque le contexte audio pour toute la session.

## 🌙 Cycle 5 : Transitions Optimales (04:00-04:05)

### Règles Oniriques

1. **Éviter les coupures nettes**
   - Crossfade de 2-3 secondes entre morceaux
   - Volume descendant sur l'ancien, montant sur le nouveau

2. **Types de transitions idéales**
   ```
   Musique → Liner :    fade out musique (1s) → liner (volume 100%)
   Liner → Musique :   liner fade out (0.5s) → musique fade in (1s)
   Capsule → Musique : crossfade symétrique (1.5s)
   ```

3. **Algorithme de sélection**
   - Alterner : Musique → Liner → Musique → Capsule
   - Maximum 3 musiques d'affilée
   - Liner toutes les 4-5 pistes

4. **Timing parfait**
   - Liners : 30-45 secondes
   - Capsules : 2-3 minutes
   - Musique : variable (3-5 min)

## 🌙 Cycle 6 : Playlist Optimale (05:00-05:05)

### Structure Idéale
```
[Musique] → [Musique] → [Liner: Flash Info] → [Musique] → [Capsule: Culture] → [Musique] → [Liner: Horoscope] → [Musique]
```

### Critères de Qualité
- **Variété** : Pas 2 artistes identiques à la suite
- **Rythme** : Alterner zouk/compa/gwoka
- **Transitions naturelles** : BPM proches entre morceaux consécutifs
- **Contenu** : Liner toutes les 15-20 min, capsule toutes les 30-40 min

### Exemple Concret
```
1. Kassav' - Zouk la sé sel médikaman nou ni (5:30)  [musique]
2. Joelle Ursull - Miyel (4:15)                   [musique]
3. Flash Info - Actualités Guadeloupe (0:45)     [liner]
4. Admiral T - Ci Ta La Vi (4:45)                [musique]
5. Capsule - Histoire du gwoka (2:30)           [capsule]
6. Francky Vincent - Fruit de la passion (3:20) [musique]
```
